# AP202 — protótipo 0.1

Primeira versão do jogo: abertura narrativa em 9:16 + efeito de máquina de escrever + primeira imagem.

## Rodar localmente

Abra `index.html` em um navegador.

Para uma experiência mais confiável com recursos locais, também pode usar um servidor local simples, como a extensão Live Server do VS Code.

## Arquivos principais

- `index.html` — estrutura da abertura e da primeira cena
- `style.css` — visual 9:16 e transições
- `game.js` — texto, efeito de digitação e som de tecla gerado no navegador
- `assets/scenes/scene-01.png` — primeira imagem enviada para o projeto

## Próximo passo

Não adicionar sistemas grandes ainda. O próximo passo recomendado é definir o que pode ser clicado nessa primeira imagem e criar a segunda cena.
